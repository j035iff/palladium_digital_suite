# UI & Wireframe Specifications

> **Implementation status:** Live sheet Persistent Core order is **Identity (top) → tool strip (Stats · Bonuses · Skills · Abilities · Gear → optional Become Morphus after Gear when dual-form · middle **TABLE** status / **Join table** · quick-ref HP/SDC/PPE/(ISP) · XP/level) → Campaigns | Combat mode switch → mode body** (`MainLayout`, `LiveSheetChromeStrip`, `LiveSheetTabBody`). Chrome label **Campaigns** (internal mode id stays `story`). Selecting a strip tab opens an **overlay** of that tab’s existing panel via `LiveSheetTabOverlay` → `LiveSheetTabBody` (one pipeline — mock Stats+Campaigns-together was screenshot artifact). Mode switch clears the overlay and shows that mode’s Home (no Home pill under the switch). **TABLE** (strip center): when seated shows the campaign/table name; when not, **Join table** opens `SheetJoinTableDrawer` + `JoinTablePanel` (shared session client / `party.snapshot` — no launcher Join / no `join_table` viewport). Peer-visible player display name uses `JOIN_PLAYER_NAME_PLACEHOLDER` until launch sign-in. **Campaigns Home** persists forever campaign tabs on the character save (`sheetCampaigns`), keyed by **normalized table/campaign name** — join reuses an existing tab when the name matches; a different name creates a new tab. Pills sort **left→right by that character’s** `lastAtTableMs` (most recent / currently seated first; oldest last) — order is per character save, never global/device-wide. The seated table’s campaign pill is **green**. Each campaign has its own **People · Places · Things · Notes** wiki journal (shared `[[kind:id|label]]` model via `ContentLinkedNotesField`; content never syncs to Hub). **Delete** / **Merge** on the seated campaign are greyed with tooltip; other campaigns stay deletable and can merge into the current-table campaign. Legacy global `playNotes` may seed the first campaign’s notes only. **Combat Home** renders `CombatHUD` `layout="panel"` with vitals cards + A.R./H.F./Perception, APM + Initiative + Melee refresh, Unarmed/Ancient/Modern bubbles (Unarmed label = active Hand-to-Hand style); strip quick-ref vitals stay visible above. Identity Expand pushes the strip and everything below down. Identity Expand edits **all** identity/profile fields (Name, Alignment, Sex, Age, Height, Weight, Eyes, Hair, **Description**, **Personality**) — **Race** and **O.C.C.** stay read-only; Height/Weight follow **Standard / Metric** units preference; **Aliases** CRUD lives on the same expand; Description / Personality are freeform player text on `identityProfile` (not catalog); Character Image remains a Radical Visibility placeholder until an image field exists. Dual-form **Become Morphus / Become Facade** sits in the strip **after Gear** (omitted with no gap when the character is not dual-form — Pillar 6). Join picks a **Name at the table** (default = real name) that peers see while the GM keeps the canonical name. Live-sheet edits stay **dirty until explicit Save**. **Abilities** nests **Natural · O.C.C. · Magic · Psionics · Talents**; empty categories are omitted. Cast / duration / pump workflow and toast/tap-to-expand attributes remain **target UX**.

This document defines the layout, visual hierarchy, and interaction design for the Palladium Digital Suite character sheet. It adheres to the Visual Continuity, Intuitive Depth, and Familiar Surface pillars: the frame stays anchored, deep math stays one tap away, and controls stay as simple and conventional as the task allows so the player never has to understand internal systems, ids, or engine terms.
1. The Persistent Core (Anchored Elements)
These elements are "anchored" to specific screen coordinates and do not move when switching between Campaigns and Combat modes. This provides a consistent frame of reference for the player.
A. Identity Header (Absolute Top)
Identity Row: One-line summary containing Name, Race, O.C.C., and Alignment (name editable inline).
Profile Expand (Expand/Minimize — not a separate overlay): **all** profile fields — Sex, Age, Height, Weight, Eyes, Hair, Alignment select — plus **Aliases** (add / rename / remove) and freeform **Description** / **Personality** textareas persisted on `identityProfile`. Height/Weight labels and inputs follow Settings → Units (Standard: Ft./In. + lbs; Metric: **cm** + kg — height is whole centimeters only, never meters) via `identityMeasures` + shared units convert helpers. **Race** and **O.C.C.** remain read-only labels (shown on the name summary row with Alignment when expanded). Expand composition: **left** stacked traits + Aliases + genre stamp, **center** prominent Description / Personality free-type boxes (clarity over exact mock style), **right** Character Image placeholder (no image field yet). Expand/Minimize lives in the Persistent Core **utility cluster** with Save / Portal (not beside the Identity label). Expanding Identity **pushes** the tool strip and mode body down (Visual Continuity — not a floating overlay).
**Save chrome (Persistent Core):** Explicit **Save** button with a Saved / Unsaved status dot beside Portal. Edits (identity, notes, gear, vitality, XP, etc.) do **not** write the character file until Save. While joined at a table, the same gate applies to peer-facing `party.snapshot` (identity / projected name / other dirty sheet fields stay local until Save). Leaving the sheet via Portal (including join-table leave) with Unsaved edits opens a dialog: **Save** or **Continue without saving** (plus Stay on sheet). One dirty/save pipeline for Campaigns and Combat — no mode fork (`src/lib/liveSheetSave.ts`).
Join Table projection: in-sheet Join drawer — player picks **Name at the table** (real name default, or an alias, or **Add alias** via dialog). Peer-visible **player** display name is `JOIN_PLAYER_NAME_PLACEHOLDER` until launch sign-in. Peers see projected character name on **At this table** (`seat.projectedCharacterName`); GM Hub keeps real `character.name`. Changing the projected name (or other identity) on the live sheet after join stays Unsaved until **Save**, which refreshes the seated snapshot.
B. Tool strip (below Identity)
Forge-style pills (`src/lib/liveSheetTabs.ts` → `buildLiveSheetOverlayTabViews`, `ForgeNavigationBar`) — **Stats · Bonuses · Skills · Abilities · Gear** then optional **Become Morphus / Become Facade** immediately after Gear when `supportsDualForm` (omitted with no empty slot otherwise — Visual Continuity). Center **TABLE** field: seated → campaign/table name; not seated → **Join table** opens `SheetJoinTableDrawer`. Selecting a strip pill opens an overlay of that tab’s content (`LiveSheetTabOverlay` + `LiveSheetTabBody`); selecting again or Close / Escape dismisses. Quick-reference pools sit in a filled chrome chip (HP / SDC / PPE / ISP when relevant). Experience chip: Level + XP → next threshold (`IdentityXpBar`).
C. Mode switch
Sticky **Campaigns | Combat** pill pair (`liveSheetModeLabel`; internal ids `story` | `combat`). No Home pill under the pair — mode Home is simply the Campaigns / Combat body when no strip overlay is open. Mode changes clear any open overlay and show that mode’s Home. Campaigns Notes use the shared wiki editor with a light **sheet** surface (`ContentLinkedNotesField` `surface="sheet"`) — wiki behavior shared with Hub; player journal content is not synced.
Bonuses overlay (`bonuses` → `SavingThrowsPanel` / `buildLiveBonusesOverlay`; **active form only**): **BONUSES** (black-outline cards) — Perception · Trust/Intimidate · Charm/Impress · Base Skill % · Base ME · Base PS Damage · Base PP · Base PE from exceptional / attribute engines. **SAVING THROWS** (blue-outline cards) — exactly the mock fixed 10 (Magic with Spell/Ritual targets, Horror Factor, Poisons/Toxins, Disease **14+**, Coma/Death %, Psionics, Illusions, Insanity, Possession, Mind Control); dynamic third row for extras (e.g. Harmful Drugs, Save vs Becoming) is **hidden until at least one extra exists**. Bonus number is most prominent; no bonus / +0 → black **—**; penalty → red; engine immunity wording as-is (**Immune** / **Impervious**); book/engine TNs as footnotes when in SoT; situational HF / Coma/Death print **varies**; Illusions / Possession omit a bottom TN until SoT has one. HF card is **save bonus only** (aura stays on CombatHUD). Hover shows the bonus breakdown. See `combat_logic.md` §4.
Abilities nests **Natural / O.C.C. / Magic / Psionics / Talents**; empty categories are omitted.
2. The Active Zone: State 1 (Campaigns)
Campaigns **Home** (`CampaignsHome`): forever campaign pills on `character.sheetCampaigns`, named by table/`campaignName` on join (`liveSheetCampaigns.ts`). Same normalized name → reuse tab; different name → new tab. Join/rejoin stamps `lastAtTableMs` on that character’s campaign row; pills sort left→right by that stamp (most recent / seated first; oldest last) — Character A’s order is independent of Character B’s. Seated table’s pill is **green**. Sub-tabs **People · Places · Things · Notes** are **per-campaign** wiki journals sharing GM Hub’s content-link model (`ContentLinkedNotesField` + `contentLinks` / placeholders). **Delete campaign** / **Merge…** live on the PPTN navy bar; when the selected campaign is the seated table, both are greyed with tooltip (`CAMPAIGN_AT_TABLE_LOCK_TOOLTIP`). Other campaigns remain deletable; other campaigns may still merge **into** the current-table campaign. Shared strip overlays **Stats / Bonuses / Skills / Abilities / Gear** reuse the same `LiveSheetTabBody` panels.
A. The Attribute Grid (2x4 Layout)
A structured grid for the 8 primary attributes (I.Q., M.E., M.A., P.S., P.P., P.E., P.B., Spd).
Numbers highlight in Green/Red if "Current Value" differs from "Base Value."
Tap-to-Expand: Shows the specific bonuses provided by that attribute (e.g., P.P. 20 shows +3 to Strike/Parry/Dodge).

B. Physical Feats & Socials Panel
Movement Hub: Displays ground, swim, and fly speed (MPH and Yards per Melee per `docs/movement_engine_spec.md`). Also includes calculated leaping distances (standing/running, horizontal/vertical).
Social Dashboard: Percentages for Trust/Intimidate (M.A. based) and Charm/Impress (P.B. based).
Lifting/Carrying: Max weight capacities based on P.S. and P.E.
3. The Active Zone: State 2 (Combat / Action)
Triggered via the **Combat mode** switch, this state opens Combat Home and shows tactical data while keeping Identity + tool strip + mode switch anchored.
A. Combat category bubbles
The Unarmed bubble **label** is the active Hand-to-Hand style (`Hand to Hand: EXPERT`, `NONE`, …). **Initiative** sits in the APM header (hover math). Three category bubbles — Unarmed (HtH name) / **Ancient Weapon** / **Modern Weapon** — show collapsed strike/parry/damage for the currently selected item. Empty weapon bubbles stay visible and **grayed** with a Gear-tab explanation (never hidden). A carried firearm still fills Modern even when the host genre has no modern W.P. rows (e.g. a Nightbane **rifted** into Palladium Fantasy) — the slot stays usable, with a short “brought from another world” note. Simple W.P. glyphs (fist / sword / rifle / whip / …) identify type — not a looter-shooter art pack.
**Expand** (one bubble at a time): Unarmed shows remaining combat-sheet totals (not Initiative), punch/kick/specials, dice, and a style picker when the character owns more than one HtH skill (same list as the Skills tab). Weapon expands include a picker of all carried Gear weapons of that era plus the full strike card (modes, ammo, traits, dice).
B. APM & Hand-to-Hand Tracker
APM Tracker: Remaining pips are tappable. Each tap spends **1** A.P.M. (left → right). Spent pips are not toggles — **New melee round** is the only refill. Multi-cost maneuvers (untrained Hand-to-Hand, power punch) = one tap per action. Implementation: `CombatHUD` `ApmPipRow`.
Hand-to-Hand Dashboard: style name replaces the Unarmed bubble title; punch/kick/specials live in the Unarmed expand. Owned styles also list on the **Skills** tab (not as percentile `SkillList` rows).

**Current Combat Home:** `CombatHUD` `layout="panel"` — vitals cards (HP/SDC/PPE/(ISP)) + A.R./H.F./Perception, tap-to-spend APM + Initiative + Melee refresh, Unarmed (HtH name) / Ancient / Modern bubbles, apply damage/heal, narrative log. Strip quick-ref stays visible above. One-tap ready-weapon icon strip is still later polish.
4. Visual Transition & Continuity Rules
Anchoring: Identity, tool strip, and mode switch stay fixed relative to each other when swapping Campaigns ↔ Combat; Identity Expand only grows downward.
The "Toast" System: Temporary changes (e.g., gaining +2 P.S. from a spell) appear as floating text "toasts" over the affected stat before fading.
Logic Transparency: Any calculated number can be tapped to reveal the underlying math (Attribute + Skill + Bonus).
